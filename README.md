# 本地 DXF 纸样查看器

在浏览器中查看 DXF，支持 GBK 中文、逐条标注拖动、悬停红色高亮与测长、两点测距、PNG 导出和打印到 PDF。服务仅监听本机回环地址，文件不会发送到外部服务，也不会覆盖原 DXF。

## 安装与启动

需要 Python 3.10 或更新版本。已在 macOS 上验证；Windows、Linux 尚未实测。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./start.sh
```

Mac 完成安装后也可双击 `启动查看器.command`。启动后自动打开浏览器，终端显示本机地址；按 Ctrl+C 停止。固定端口启动：`./start.sh --port 59721`。不要将当前服务直接暴露到公网，它没有账号认证和生产级并发隔离。

## 使用

- 选择或拖入 DXF（最大 30 MB）；可切换 GBK、UTF-8、Big5、CP1252。
- 滚轮缩放，拖动空白平移；每条文字标注可单独拖动，“恢复标注位置”还原。
- 悬停红色高亮当前测量段，显示长度；多段线按拐点切分，默认转向角阈值 25°，可调整。平滑曲线不按每个采样顶点拆分，闭合曲线无拐点时保留整条。
- 两点测距为自由点选的平面直线距离，不吸附端点。
- PNG 和打印结果包含当前标注位置及测量辅助线，但不包含临时悬停高亮。
- 切换编码、图层或拐点阈值会重新渲染，清除临时移动和测量。

## 单位、字体与准确性

**当前页面按原使用者确认，将 1 绘图单位视为 1 mm。** 其他来源文件须先确认单位，不可将本工具显示的 mm 当作文件自带的单位声明。

无编码声明时的编码为推断，可手动覆盖。中文标注保留原锚点与角度，用系统中文字体显示，字宽可能与制版软件不同；不翻译或更改原文。macOS 使用 Arial Unicode MS / PingFang SC。其他系统需自行安装中文字体，几何渲染的字体路径可通过 `DXF_FONT_PATH` 环境变量指定。不附带商业字体。

拐点由转向角推断，不保证与制版软件内部的业务分段相同。直线和标准圆弧使用几何长度；其他曲线按近似采样求长并标“约”。工具仅适合辅助查看，不用于生产级 1:1 出图。未知实体的测量可能不受支持。

## 验证

```sh
.venv/bin/python -m unittest discover -s tests -v
```

仅包含合成测试数据；不包含客户纸样、截图、报告或本机运行环境。

## 架构

`server.py` 使用 ezdxf 解析并输出 SVG；`index.html` 负责显示和交互。临时解析副本自动清理；源文件保持只读。上传处理使用 Python 标准库 HTTP 服务，适合本机单用户运行。
